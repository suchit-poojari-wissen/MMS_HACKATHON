# Overview

## Purpose
Build an AI-driven Maintenance Management System that ingests manuals, SOPs, breakdown reports and other documentation and provides a guided diagnostics assistant. The system combines OCR, document structure extraction, chunking, knowledge graph construction, vector embeddings, hybrid retrieval, optional GNN reasoning, and LLM-based diagnostic assistance.

## Scope
- Support digital and scanned documents (PDF, DOCX, PPTX, images)
- Preserve tables and diagrams as first-class artifacts
- Provide hybrid Graph+Vector retrieval for high precision
- Support offline KG updates and online query-time reasoning
- Optional GNN module to enhance root-cause predictions
- Cloud LLMs for final reasoning (Azure OpenAI / OpenAI / Foundry)

## Audience
- Engineering teams building the system
- DevOps teams deploying to Azure
- Product managers reviewing functionality and timeline
